# Product Requirements Document
# 한국어 학습 자원 후기 플랫폼
## MVP — 학습 유형 기반 후기 검색 엔진

버전 1.0 | 2026년 3월
기술 스택: Next.js | 레퍼런스: 왓챠피디아 한국어 학습 버전

## 1. 제품 개요

### 1.1 한 줄 정의

> 왓챠피디아의 한국어 학습 버전 — 학습 유형이 태깅된 후기 검색 엔진

### 1.2 배경 및 문제 정의

한국어 학습 자원은 이미 충분히 존재하지만 산재되어 있어, 학습자가 자신의 수준과 목적에 맞는 자원을 찾기 어렵다. 기존 앱스토어 별점은 맥락이 없어 신뢰도가 낮다. 특히 해외 거주 학습자는 "나와 같은 유형의 학습자가 이 앱을 어떻게 평가했는가"를 알 방법이 없다.

- **기존 앱스토어 후기:** 학습 수준·목적·유형 정보 없이 단순 별점만 존재
- **레딧 r/Korean 등 커뮤니티:** 후기가 산발적이고 검색·필터 기능 없음
- **해외 거주 학습자:** 오프라인 교육 접근성이 낮아 앱 선택에 더 의존적

### 1.3 핵심 차별화

후기에 작성자의 학습 유형이 자동 태깅되어, 검색자가 자신과 유사한 유형의 후기를 우선 참고할 수 있다.

| 구분 | 기존 앱스토어 | 이 플랫폼 |
|---|---|---|
| 후기 맥락 | 없음 | 학습 유형 + 수준 + 목적 태그 |
| 검색 필터 | 없음 | 앱명 / 수준 / 목적 / 학습 유형 |
| 유형별 평점 | 없음 | "시각+구조형 학습자의 평균 별점 4.2" |
| 한국어 학습 특화 | 없음 | 한국어 학습자 전용 커뮤니티 |

### 1.4 타깃 유저

- 제2외국어로 한국어를 학습하는 해외 거주 외국인
- 오프라인 교육 접근성이 낮아 앱·서비스 선택에 의존적인 학습자
- 주요 세그먼트: K-pop·드라마 입문자(10~20대), 비즈니스 목적 성인 학습자

### 1.5 MVP 검증 목표

> 핵심 질문: 학습 유형이 태깅된 후기가 앱 선택에 실질적으로 도움이 되는가?

- 소프트 론칭 2주 내 후기 작성 완료율 50% 이상 (검사 시작 → 후기 제출 완료)
- "이 후기가 앱 선택에 도움이 됐나요?" 긍정 응답 60% 이상
- 유저 인터뷰 10건 이상 수집

## 2. MVP 기능 범위

### 2.1 In Scope — 구현할 것

**① 메인 페이지 — 후기 검색 엔진**
- 앱/서비스 카드 목록 (8개) 표시
- 검색 필터: 앱명 / 학습 수준 / 학습 목적 / 학습 유형
- 각 앱 카드에 전체 평균 별점 + 유형별 평균 별점 표시
- 앱 카드 클릭 시 해당 앱의 후기 목록 페이지로 이동

**② 앱 상세 페이지 — 후기 목록**
- 앱 기본 정보 (이름, 카테고리, 링크, 플랫폼 설명)
- 전체 평균 별점 + 학습 유형별 평균 별점 (유형 A~F)
- 후기 목록: 학습 유형 태그 + 별점 + 서술 + 캡처 사진
- 후기 필터: 학습 유형 / 수준 / 별점순 / 최신순
- "후기 작성하기" CTA 버튼

**③ 후기 작성 플로우**

후기 작성은 3단계로 진행된다. 학습 유형 검사는 최초 1회만 진행하며, 이후 작성 시에는 저장된 유형을 그대로 사용한다.

| 단계 | 화면 | 내용 |
|---|---|---|
| 1단계 | 학습 유형 검사 | 간소화 10문항 진행 (최초 1회만) → 유형 A~F 판별 후 로컬스토리지 저장 |
| 2단계 | 후기 기본 정보 | 학습 수준 선택 / 학습 목적 선택 / 해당 앱 사용 기간 입력 |
| 3단계 | 후기 작성 | 별점 (5점 만점) / 서술 텍스트 / 캡처 사진 업로드 (선택) / 제출 |

**④ 후기 표시 형식**

작성된 후기는 아래 형식으로 표시된다. 학습 유형 태그가 핵심 차별화 요소다.

> 표시 예시: 시각 + 구조형 학습자는 이 앱을 ★★★★☆ (4점)으로 평가했습니다.

- 후기 카드 구성: [학습 유형 뱃지] [별점] [수준] [목적] [사용 기간] [서술] [캡처 사진]
- 유형별 평균 별점은 해당 유형 후기가 1개 이상일 때부터 표시

**⑤ 회원가입 없이 작성 가능 (MVP)**
- 학습 유형 검사 결과는 브라우저 로컬스토리지에 저장
- 후기 작성 시 닉네임만 입력 (이메일·비밀번호 불필요)
- 동일 브라우저에서 재작성 시 유형 검사 스킵

### 2.2 Out of Scope — 이번 MVP 제외

- 회원가입 / 로그인 / 마이페이지
- 커리큘럼 추천 엔진 (이전 MVP 기능 — 2단계에서 통합)
- AI 튜터 / 튜터 마켓플레이스
- 커뮤니티 게시판 / Q&A
- 후기 좋아요 / 댓글 / 신고
- 유료 결제

## 3. 학습 유형 검사 — 간소화 버전 (10문항)

### 3.1 채점 로직

2축 분류 체계를 그대로 사용한다. 10문항은 감각 축(Q1~Q3)과 방식 축(Q4~Q10)으로 구성된다.

| 번호 | 축 | 방향 | 채점 방식 |
|---|---|---|---|
| Q1~Q2 | 감각 축 | 시각형 | 합산 → visualScore |
| Q3 | 감각 축 | 청각형 | 합산 → auditoryScore |
| Q4 | 방식 축 | 탐색형 | styleScore에서 차감 (−) |
| Q5~Q10 | 방식 축 | 구조형 | styleScore에 가산 (+) |

- 감각 축: visualScore vs auditoryScore 비교. 차이 ≤ 4점이면 복합형(mixed)
- 방식 축: styleScore 합산. 양수이면 구조형, 음수이면 탐색형
- 결과: 6개 유형 중 하나로 분류 (A~F)
- 응답 척도: 1(전혀 아니다) ~ 5(매우 그렇다)

### 3.2 유형 분류 결과표

| 유형 | 감각 | 방식 | 설명 |
|---|---|---|---|
| A | 시각 | 탐색형 | 보면서 맥락 속에 자연스럽게 흡수하는 학습자 |
| B | 시각 | 구조형 | 보면서 체계적으로 정리하며 쌓아가는 학습자 |
| C | 청각 | 탐색형 | 들으면서 자연스럽게 언어를 흡수하는 학습자 |
| D | 청각 | 구조형 | 들으면서 규칙을 파악하고 체계화하는 학습자 |
| E | 시각+청각 | 탐색형 | 시청각 모두 활용하며 맥락으로 흡수하는 학습자 |
| F | 시각+청각 | 구조형 | 시청각 모두 활용하며 체계적으로 정리하는 학습자 |

### 3.3 10문항 전체 목록

| # | 한국어 | English | 축 | 방향 |
|---|---|---|---|---|
| 1 | 나는 배울 때 그림, 도표, 차트를 보는 것을 좋아한다. | I like to see pictures, diagrams, or charts when learning. | 감각 축 | 시각형 |
| 2 | 나는 공부할 때 텍스트에 하이라이트나 밑줄을 긋는 것이 도움이 된다. | I find it helpful to highlight or underline text when studying. | 감각 축 | 시각형 |
| 3 | 나는 강의나 오디오를 들을 때 더 잘 배운다. | I learn better when I listen to lectures or audio. | 감각 축 | 청각형 |
| 4 | 나는 무엇이 효과가 있는지 찾기 전에 실험하고 다양한 방법을 시도하는 것을 좋아한다. | I like to experiment and try different approaches before finding what works. | 방식 축 | 탐색형 |
| 5 | 나는 새로운 것을 배우기 전에 상세한 계획을 세우는 것을 좋아한다. | I like having a detailed plan before starting to learn something new. | 방식 축 | 구조형 |
| 6 | 나는 배울 때 명확한 가이드라인과 규칙이 필요하다. | I need clear guidelines and rules when learning. | 방식 축 | 구조형 |
| 7 | 나는 학습 진행 상황이 추적되고 측정되는 것을 좋아한다. | I like to have my learning progress tracked and measured. | 방식 축 | 구조형 |
| 8 | 나는 문법 규칙과 구조를 명시적으로 공부하는 것을 선호한다. | I prefer studying grammar rules and structures explicitly. | 방식 축 | 구조형 |
| 9 | 나는 모든 규칙 뒤에 있는 "왜"를 이해하고 싶다. | I want to understand the "why" behind every rule. | 방식 축 | 구조형 |
| 10 | 나는 내 진행 상황을 확인하기 위해 퀴즈와 시험을 보는 것을 좋아한다. | I like having quizzes and tests to check my progress. | 방식 축 | 구조형 |

## 5. 유저 플로우

### 5.1 후기 탐색 플로우 (비작성자)

1. 메인 페이지 진입 → 앱 카드 목록 확인
2. 필터 적용 (수준 / 목적 / 학습 유형) → 해당 앱 카드 필터링
3. 앱 카드 클릭 → 앱 상세 페이지
4. 유형별 평균 별점 확인 → 후기 목록 탐색
5. 후기 필터 적용 (자신의 학습 유형과 유사한 후기 우선 확인)

### 5.2 후기 작성 플로우

1. 앱 상세 페이지 → "후기 작성하기" 클릭
2. [최초 1회] 학습 유형 검사 10문항 진행 → 유형 판별 → 로컬스토리지 저장
3. [재방문] 저장된 유형 확인 화면 → "이 유형으로 계속하기" 또는 "다시 검사하기"
4. 학습 수준 / 목적 / 앱 사용 기간 선택
5. 별점 입력 (5점 만점) + 서술 작성 + 캡처 사진 업로드 (선택)
6. 닉네임 입력 → 제출
7. 완료 화면: "내 후기 보기" + "다른 앱 후기 작성하기" CTA

## 9. MVP 이후 로드맵

**2단계 — 두 MVP 통합 (6~12개월)**
- 이전 MVP(커리큘럼 추천 엔진)와 통합: 후기 데이터가 추천 알고리즘의 협업 필터링 데이터로 활용
- 회원가입·로그인 도입 → 마이페이지 (내 유형 / 내 후기 / 추천 커리큘럼)
- 진도 트래킹 + AI 튜터 베타
- 유료 코어 티어 전환

**3단계 — 플랫폼 확장 (12개월~)**
- 앱 DB 확장 (커뮤니티가 직접 추가 요청 가능)
- 원어민 튜터 마켓플레이스 + 커리큘럼 연동 세션 어젠다
- 외부 앱 개발사와 번들 할인 제휴
